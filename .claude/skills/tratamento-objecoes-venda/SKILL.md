# Tratamento de objeções

Técnica: **acolher → reenquadrar → provar → avançar**. Nunca discutir; conduzir.

| Objeção | Resposta-chave |
|---|---|
| "Já controlo no caderno" | O caderno guarda, mas não **cobra**. O app te diz **quem cobrar hoje** e já escreve a mensagem. O caderno continua, só que trabalhando por você. |
| "É caro" | Quanto é **um calote médio** na sua loja? O app custa menos que isso — e ajuda a evitar vários. |
| "Não tenho tempo de cadastrar" | Começamos só com os **10 maiores devedores**. Em uma semana você já vê dinheiro voltando. |
| "Minha cliente não é de app" | Quem usa o app é **você**. A cliente só recebe uma mensagem no WhatsApp, como sempre. |
| "Vou pensar" | Faz sentido. Que tal um **teste sem compromisso** com 10 clientes? Se não voltar dinheiro, você para. |
| "Tenho medo de ofender o cliente" | O app ajusta o **tom** (amigável, lembrete, firme) e respeita o Código de Defesa do Consumidor. Cobrança educada fideliza. |

## Princípios
- Toda objeção é um pedido de prova. Responda com **número** ou **teste**.
- Reduza o risco percebido: teste pequeno, começo pelos maiores devedores.
- Sempre termine com uma **pergunta de avanço**.
